# Pedro Baez

**Desarrollador full stack · Buenos Aires, Argentina**

Hago sistemas y sitios para negocios reales: comercios, restaurantes, barberías y emprendimientos.<br/>
Desde la página donde el cliente compra o reserva hasta el panel donde el dueño maneja stock, caja y turnos.

## Qué hago

- 🧾 **Sistemas de gestión a medida** — stock, caja, turnos, comandas, fiados y reportes, con roles y permisos.
- 🛒 **Tiendas online y SaaS** — vidrieras con pedidos por WhatsApp, multi-tenant, cada comercio con su propio subdominio.
- 🌐 **Landing pages que venden** — rápidas, accesibles y pensadas para que el visitante escriba o compre.
- 🤖 **IA aplicada al negocio** — asesores que consultan el catálogo real de la tienda en vez de contestar de memoria.
